# webgl-terrain

실제 한국 지형 위에서 수위를 조절하며 침수 지역과 대피소의 침수 여부를 확인하는 3D 웹 시뮬레이터입니다.
라이브러리 없이 순수 WebGL2와 GLSL로 구현했습니다.

## 주요 기능

- **실제 지형 표시**: 고도 타일 데이터로 제주도 지형을 3D로 렌더링
- **수위 시뮬레이션**: 슬라이더로 수위를 조절하면 잠기는 지역을 실시간으로 표시
- **대피소 침수 상태**: 대피소의 해발고도와 수위를 비교해 색으로 표시
  - 🟢 안전 · 🟡 위험(1m 이내) · 🔴 침수
- **영향 통계**: 침수 면적과 침수·위험 대피소 수
- **대피소 정보**: 마커를 클릭하면 이름, 해발고도, 남은 높이를 표시

## 조작법

| 입력 | 동작 |
|---|---|
| 드래그 | 회전 |
| 마우스 휠 | 확대 / 축소 |
| W A S D | 이동 |
| 마커 클릭 | 대피소 정보 |

## 기술 스택

JavaScript (ES Modules) · WebGL2 · GLSL ES 3.0

## 데이터 출처

- 지형: [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)
- 대피소: 행정안전부 지진해일 긴급대피장소
